# Dawnwalker Controller Tweaks

Controller improvements for *The Blood of Dawnwalker* on PC.

- **Swap shoulders and triggers:** LB ↔ LT and RB ↔ RT (PlayStation L1 ↔ L2 and R1 ↔ R2).
- **Easier walking:** raises the left-stick walk-to-run threshold from 0.70 to 0.90.
- **Tap for Map, hold for Game Hub:** tap Back/View (PlayStation touchpad) for the map; hold for 0.30 seconds to open the hub.

With the default layout, Block moves to LT, Focus Mode/Combat Abilities to LB, Attack/Overworld Abilities to RT, and Shadowstep to RB. The button swap also applies in Photo Mode.

## Installation

No other mods or loaders are required.

1. Download **Dawnwalker-Controller-Tweaks.zip** from [Releases](https://github.com/my-mods/Dawnwalker-Controller-Tweaks/releases).
2. Install it through Vortex as **Root (game folder)**, then enable and deploy.

To uninstall, disable/remove the mod and deploy through Vortex.

## Compatibility

Uses the default controller preset. Game and Steam Input deadzone settings affect the walking range; full-stick movement and sprint bindings are preserved.

Replaces `IA_Move`, `IA_Hub_Launch`, `IA_Hub_Map`, and `RIP_GamepadDefault`. Other mods changing these assets need a compatibility patch, even if Vortex shows no file conflict.

Based on Steam build **25129649 / CL-257186**. Later versions are unverified.

Game assets belong to their respective rightsholders.
