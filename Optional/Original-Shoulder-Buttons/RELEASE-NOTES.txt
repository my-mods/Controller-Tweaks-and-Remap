Original Shoulder Buttons - optional preset 1.5.2

Updated documentation and diagnostic-setting example for the current main
release. The eight original shoulder-button bindings are unchanged. Existing
users who already use this preset do not need to replace their personal INI.

Requires Controller Tweaks and Remap 1.4.0 or newer and compatible UE4SS.
Manual download and personal-profile configuration only. Back up your INI
before replacing it. Replacement overwrites all existing preferences; it
does not merge them. To preserve other settings, manually copy/update only
the documented entries in the existing sections. See README.txt.
