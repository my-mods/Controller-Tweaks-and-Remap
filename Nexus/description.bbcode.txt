[size=5][b][color=#E8C88A]Controller Tweaks and Remap[/color][/b][/size]

More comfortable controller input for The Blood of Dawnwalker on PC: swap shoulders and triggers, make walking easier, and open the Map or Game Hub with a short press or long press of the same button.

[size=4][b][color=#E8C88A]Features[/color][/b][/size]

[size=3][b][color=#A8D5C2]Configurable controller mappings[/color][/b][/size]

Configure all 31 Default and Alternative controller bindings with a personal INI. The file documents every action, supported key name, Xbox alias and PlayStation equivalent. Settings load at startup; the main file keeps the existing layout by default.

[size=3][b][color=#A8D5C2]Linked Voracious Bite controls[/color][/b][/size]

Player_Drink_Blood controls both starting Bite in Focus and holding to feed. Necrospeak in Focus shares this button. Normal Interact and Death from Above keep their own bindings. Default uses X/Square; Alternative uses LB/L1 to avoid Attack on X/Square. If an old personal INI explicitly sets Player_Drink_Blood=X, change it to LB or comment it out when using Alternative. Keep Bite different from Attack and Focus. Keyboard Focus Bite/Necrospeak also follow the game's Drink Blood key.

[size=3][b][color=#A8D5C2]Controller stutter fixes (1.5.2)[/color][/b][/size]

Stops completed background checks and combines duplicate input events so they do not repeatedly restart controller updates. Larger updates are spread across frames, and controls recover when needed after loading or controller preset changes. INI edits still require a restart.

[size=3][b][color=#A8D5C2]Shoulder / trigger swap[/color][/b][/size]

Swaps LB with LT and RB with RT in the default controller preset. PlayStation equivalents are L1 with L2 and R1 with R2.
[list]
[*][b][color=#A8D5C2]Block:[/color][/b] LT / L2.[/*]
[*][b][color=#A8D5C2]Focus Mode / Combat Abilities:[/color][/b] LB / L1.[/*]
[*][b][color=#A8D5C2]Attack / Overworld Abilities:[/color][/b] RT / R2.[/*]
[*][b][color=#A8D5C2]Shadowstep:[/color][/b] RB / R1.[/*]
[/list]
The swap also applies in Photo Mode.

[size=3][b][color=#A8D5C2]Easier walking[/color][/b][/size]

Gives you a wider stick range for walking. Shapeshift and Mercurial Fervour stay active when you steer with the stick fully pushed. Sprint bindings are preserved.

[size=3][b][color=#A8D5C2]Short press Map / long press Game Hub[/color][/b][/size]

On Back/View (PlayStation touchpad):
[list]
[*][b][color=#A8D5C2]Short press:[/color][/b] open the Map.[/*]
[*][b][color=#A8D5C2]Long press (0.30 seconds):[/color][/b] open the Game Hub.[/*]
[/list]
[size=4][b][color=#E8C88A]Requirements[/color][/b][/size]

Install [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/18]UE4SS for Dawnwalker[/url] following its instructions.

[size=4][b][color=#E8C88A]Installation[/color][/b][/size]

[list]
[*][b][color=#A8D5C2]Vortex:[/color][/b] Install Controller-Tweaks-and-Remap.zip through Vortex, enable it and deploy.
[*][b][color=#A8D5C2]Manual:[/color][/b] Copy the archive's Dawnwalker folder into ...\steamapps\common\The Blood of Dawnwalker\, preserving the folder structure.
[/list]

[size=4][b][color=#E8C88A]Configuration[/color][/b][/size]

Launch once with the mod, close the game, then open [b]%LOCALAPPDATA%/Dawnwalker/Saved/Config/ControllerTweaks.ini[/b]. Uncomment and edit only the settings you want to change; save and restart. Personal edits do not need Vortex deployment.

The personal INI is created only when missing and includes a full commented layout. Default uses the shipped INI layout; Alternative uses its original layout with Bite/feeding on LB/L1. Active personal values override either selected preset. Omitted/commented values inherit that preset's defaults. An old INI with every entry active overrides the entire layout. The included ControllerTweaks.defaults.ini has the latest binding explanations; old personal reference comments are preserved. The mod never rewrites an existing personal INI, and the main archive contains no personal INI, so updates preserve your edits. An invalid INI is left untouched and reported in UE4SS.log. Keep Player_Hub_Map and Player_Hub_Launch on the same control for their shared shortcut.

[size=3][b][color=#A8D5C2]Optional file: Original Shoulder Buttons[/color][/b][/size]

Download Dawnwalker-Controller-Tweaks-Original-Shoulder-Buttons.zip (preset 1.5.2) manually. The eight bindings are unchanged; existing preset users do not need to replace their personal INI. It requires main version 1.4.0 or newer and UE4SS. Use this optional preset with Default. It restores Block to LB/L1, Focus Mode and Combat Abilities to LT/L2, Attack and Overworld Abilities to RB/R1, Shadowstep to RT/R2, and Photo Mode rise/fall to RT/R2 and LT/L2. Walking and Map/Game Hub tweaks remain active.

With the game closed, back up your personal INI. If you have no preferences to keep, copy the optional ControllerTweaks.ini into the personal Config folder above. [b][color=#E6B980]Replacing it replaces all existing preferences; it does not merge them.[/color][/b] To preserve other settings, set Enabled=true under your existing [General] section and copy/update only the eight active binding entries under your existing [Bindings] section, avoiding duplicates. The included README lists them all. Restart the game. Do not import this optional preset into Vortex or copy it into the game folder.

There is no in-game configuration menu. Cached button prompts may retain their previous labels.
