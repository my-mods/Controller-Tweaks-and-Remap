[size=5][b]Dawnwalker Controller Tweaks[/b][/size]
More comfortable controller input for The Blood of Dawnwalker on PC: swap shoulders and triggers, make walking easier, and open the Map or Game Hub with a short press or long press of the same button.

[size=4][b]Features[/b][/size]
[b]Shoulder / trigger swap[/b]
Swaps LB with LT and RB with RT in the default controller preset. PlayStation equivalents are L1 with L2 and R1 with R2.
[list]
[*]Block: LT / L2.
[*]Focus Mode / Combat Abilities: LB / L1.
[*]Attack / Overworld Abilities: RT / R2.
[*]Shadowstep: RB / R1.
[/list]
The swap also applies in Photo Mode.

[b]Easier walking[/b]
Raises the left-stick walk-to-run threshold from 0.70 to 0.90, giving you a wider stick range for walking. Full-stick movement and sprint bindings are preserved. Game and Steam Input deadzone settings affect the walking range you feel.

[b]Short press Map / long press Game Hub[/b]
On Back/View (PlayStation touchpad):
[list]
[*]Short press: open the Map.
[*]Long press (0.30 seconds): open the Game Hub.
[/list]

[size=4][b]Requirements[/b][/size]
The Blood of Dawnwalker on PC, a controller, and the default controller preset. No other mods or loaders are required; UE4SS and HUDTweaks are not needed.

[size=4][b]Installation[/b][/size]
[list=1]
[*]Download Dawnwalker-Controller-Tweaks.zip.
[*]Import the ZIP directly into Vortex 1.14 or newer and install it as [b]Root (game folder)[/b].
[*]Enable the mod and deploy through Vortex.
[*]Use the default controller preset in the game.
[/list]
The runtime files are zzz_DawnwalkerControllerTweaks_P.pak, .ucas and .utoc, installed together under Dawnwalker/Content/Paks/~mods/.

[b]Updating[/b]
Use Vortex's replace/reinstall flow on the existing mod entry with the new ZIP, then deploy. Keep one enabled Controller Tweaks entry. See the release notes for upgrade steps from older packages.

[b]Uninstalling[/b]
Disable or remove the mod in Vortex, then deploy.

[size=4][b]Compatibility and configuration[/b][/size]
This is a fixed controller preset and input-asset replacement. There is no INI or in-game configuration menu for this mod.

Replaces [b]IA_Move[/b], [b]IA_Hub_Launch[/b], [b]IA_Hub_Map[/b] and [b]RIP_GamepadDefault[/b]. Other mods changing any of these assets need a compatibility patch. Different container filenames can still replace the same assets, so Vortex may show no file conflict. Load order alone cannot combine two edits to the same asset.

Standalone shoulder/trigger swap and TapMapHoldMenu/controller compatibility mods are superseded by this combined mod; disable them through Vortex before using it. HUDTweaks can be used independently: this package contains no HUDTweaks script or configuration overrides.

Based on Steam build [b]25129649 / CL-257186[/b]. Controller behavior has been confirmed working in game. Later game builds are unverified.
