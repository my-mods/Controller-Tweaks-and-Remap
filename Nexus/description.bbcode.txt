[size=5][b]Controller Tweaks and Remap[/b][/size]
More comfortable controller input for The Blood of Dawnwalker on PC: swap shoulders and triggers, make walking easier, and open the Map or Game Hub with a short press or long press of the same button.

[size=4][b]Features[/b][/size]
[b]Configurable controller mappings[/b]
Configure all 31 Default and Alternative controller bindings with a personal INI. The file documents every action, supported key name, Xbox alias and PlayStation equivalent. Settings load at startup; the main file keeps the existing layout by default.

[b]Linked Voracious Bite controls[/b]
Player_Drink_Blood controls both starting Bite in Focus and holding to feed. Necrospeak in Focus shares this button. Normal Interact and Death from Above keep their own bindings. Default uses X/Square; Alternative uses LB/L1 to avoid Attack on X/Square. If an old personal INI explicitly sets Player_Drink_Blood=X, change it to LB or comment it out when using Alternative. Keep Bite different from Attack and Focus. Keyboard Focus Bite/Necrospeak also follow the game's Drink Blood key.

[b]Controller stutter fixes (1.5.2)[/b]
Stops completed background checks and combines duplicate input events so they do not repeatedly restart controller updates. Larger updates are spread across frames, and controls recover when needed after loading or controller preset changes. INI edits still require a restart.

[b]Shoulder / trigger swap[/b]
Swaps LB with LT and RB with RT in the default controller preset. PlayStation equivalents are L1 with L2 and R1 with R2.
[list]
[*]Block: LT / L2.[/*]
[*]Focus Mode / Combat Abilities: LB / L1.[/*]
[*]Attack / Overworld Abilities: RT / R2.[/*]
[*]Shadowstep: RB / R1.[/*]
[/list]
The swap also applies in Photo Mode.

[b]Easier walking[/b]
Gives you a wider stick range for walking. Shapeshift and Mercurial Fervour stay active when you steer with the stick fully pushed. Sprint bindings are preserved.

[b]Short press Map / long press Game Hub[/b]
On Back/View (PlayStation touchpad):
[list]
[*]Short press: open the Map.[/*]
[*]Long press (0.30 seconds): open the Game Hub.[/*]
[/list]

[size=4][b]Requirements[/b][/size]
Install [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/18]UE4SS for Dawnwalker[/url] following its instructions.

[size=4][b]Vortex Installation[/b][/size]

Install UE4SS first. Import Controller-Tweaks-and-Remap.zip into Vortex as [b]Root (game folder)[/b], enable it and deploy. Select Default or Alternative, then restart the game.

[b]Updating[/b]
Use Vortex's replace/reinstall flow on the existing Controller Tweaks and Remap entry, then deploy. Keep one enabled entry and restart the game. Personal settings are preserved. For Alternative, change an explicit Player_Drink_Blood=X to LB or comment it out to use the new default. Earlier standalone shoulder/trigger and TapMapHoldMenu/controller compatibility mods are superseded. If you previously edited an INI inside the mod folder, back it up before replacement and transfer desired settings into the personal INI.

[size=4][b]Manual installation[/b][/size]

After installing UE4SS separately, extract the main archive's Dawnwalker folder into the game root, preserving paths. The three zzz_DawnwalkerControllerTweaks_P containers go under Dawnwalker/Content/Paks/~mods/; the Lua mod goes under Dawnwalker/Binaries/Win64/ue4ss/Mods/DawnwalkerControllerTweaks/. Keep README, license and other release documents outside runtime folders.

[b]Uninstalling[/b]
Disable/remove the mod in Vortex and deploy. For a manual installation, remove its three named containers and the DawnwalkerControllerTweaks Lua mod folder. The personal INI remains in your profile for future use.

[size=4][b]Compatibility and configuration[/b][/size]
Launch once with the mod, close the game, then open [b]%LOCALAPPDATA%/Dawnwalker/Saved/Config/ControllerTweaks.ini[/b]. Uncomment and edit only the settings you want to change; save and restart. Personal edits do not need Vortex deployment.

The personal INI is created only when missing and includes a full commented layout. Default uses the shipped INI layout; Alternative uses its original layout with Bite/feeding on LB/L1. Active personal values override either selected preset. Omitted/commented values inherit that preset's defaults. An old INI with every entry active overrides the entire layout. The included ControllerTweaks.defaults.ini has the latest binding explanations; old personal reference comments are preserved. The mod never rewrites an existing personal INI, and the main archive contains no personal INI, so updates preserve your edits. An invalid INI is left untouched and reported in UE4SS.log. Keep Player_Hub_Map and Player_Hub_Launch on the same control for their shared shortcut.

[b]Optional file: Original Shoulder Buttons[/b]
Download Dawnwalker-Controller-Tweaks-Original-Shoulder-Buttons.zip manually. It requires main version 1.4.0 or newer and UE4SS. Use this optional preset with Default. It restores Block to LB/L1, Focus Mode and Combat Abilities to LT/L2, Attack and Overworld Abilities to RB/R1, Shadowstep to RT/R2, and Photo Mode rise/fall to RT/R2 and LT/L2. Walking and Map/Game Hub tweaks remain active.

With the game closed, back up your personal INI. If you have no preferences to keep, copy the optional ControllerTweaks.ini into the personal Config folder above. [b]Replacing it replaces all existing preferences; it does not merge them.[/b] To preserve other settings, set Enabled=true under your existing [General] section and copy/update only the eight active binding entries under your existing [Bindings] section, avoiding duplicates. The included README lists them all. Restart the game. Do not import this optional preset into Vortex or copy it into the game folder.

To remove the preset, comment out/remove those eight overrides and restart. The main mod's swap returns; other personal settings remain. There is no in-game configuration menu. Cached button prompts may retain their previous labels.

Other mods that change walking or controller controls may conflict.
